# Sohana POS

Billing, khata, stock and cash app for SOHANA TRADERS, Sukkur, by Kodexa.
One Android phone, 58mm Bluetooth memo printer (MPT-II), English or Urdu memos, bills shared on WhatsApp.

The web build is the client demo: same app, sample data in the browser, resets on refresh.

```bash
npm install
npm run web          # develop
npm run build:web    # export to dist/
npm run serve        # serve dist/ with the headers SQLite needs
```

See `CLAUDE.md` for the rules, layout and gotchas.
